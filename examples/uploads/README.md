# Example Upload Files

These five CSVs use the same schema the upload box expects:

```csv
date,category,amount,customer_id
```

They are meant to be downloaded from GitHub and uploaded directly into the app without editing.

Files included:

- `saas_recovery_arc.csv`: B2B SaaS company recovering from churn.
- `fintech_runway_reset.csv`: Fintech company with a tax hit and cost pressure.
- `healthtech_enterprise_mix.csv`: Healthtech company with larger enterprise customers.
- `marketplace_margin_crunch.csv`: Marketplace-style business with heavier COGS.
- `devtools_plg_growth.csv`: Devtools company with product-led growth momentum.

Supported categories used here:

- `subscription_revenue`
- `churn_refund`
- `salary_expense`
- `software_expense`
- `marketing_expense`
- `cogs`
- `tax_payment`
